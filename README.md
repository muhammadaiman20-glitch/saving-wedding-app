# 💍 Saving Wedding App

A modern web application to help couples track their wedding savings, manage expenses, and plan their dream wedding budget.

## ✨ Features

- 💰 **Wedding Savings Tracker** - Track progress toward your wedding savings goal with a beautiful visual progress bar
- 💸 **Income & Expenses** - Manage your income and track wedding-related expenses
- 📋 **Debt Manager** - Keep track of any debts that need to be cleared before the wedding
- 🔄 **Subscription Manager** - Monitor recurring subscriptions to optimize your budget
- 🤖 **AI Advisor** - Get personalized advice on saving strategies and budget planning
- 📸 **Receipt Scanner** - Scan and save receipts with OCR technology

## 🚀 Run locally on Windows

Double-click `start.bat` to:

- Install dependencies if needed
- Start the frontend on http://localhost:3001
- Start the backend on http://localhost:3002
- Open the frontend in Google Chrome automatically

## 💡 How to use

Once the app is running:

1. **Wedding Savings**: Navigate to the "Savings" tab in the app to see your wedding savings progress. Use the transfer button to add money to your wedding account.
2. **Track Progress**: Watch your savings grow with the beautiful progress bar and milestone celebrations.
3. **Manage Finances**: Use the Income/Expenses, Debt, and Subscription tabs to get a complete picture of your finances.

## 🛠️ Tech Stack

- **Frontend**: Next.js, React, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express
- **AI**: OpenAI API for smart advisor features
- **OCR**: Tesseract.js for receipt scanning
